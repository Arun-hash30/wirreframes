How to read this:
• Solid boxes = content blocks/cards. Dashed boxes = images, screenshots, free-text inputs.
• Progress bars + "%" = OKR / KR completion, styled after Weekdone's progress-first dashboards.
• Pills = status tags (Submitted / Overdue / Auto-flagged / Private). Avatars = team member references.
• Left sidebar is the persistent app nav (Dashboard, OKRs, Check-ins, Tasks, 1:1s, Feedback, Reviews, Reports) — mirrors Weekdone's left-rail IA rather than a marketing top-nav.
• Tabs above switch between the 5 core screens; each shown in Laptop (sidebar + content) and Mobile (bottom tab bar).
• Phase/priority per feature (MVP, P2, P3) is called out in each screen's subtitle, matching the feature table.
